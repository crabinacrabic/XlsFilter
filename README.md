# XlsFilter Unified — Аналитический фильтр и обработчик таблиц на Delphi

> [!IMPORTANT]
> **ОФИЦИАЛЬНОЕ УВЕДОМЛЕНИЕ (ДИСКЛЕЙМЕР ИИ):**  
> Все наборы данных, номера документов, статьи, процессуальные решения и фамилии в данном репозитории сгенерированы и модифицированы с использованием искусственного интеллекта (ИИ) исключительно в учебных, исследовательских и демонстрационных целях. В фамилиях намеренно изменена 1 буква для исключения персональной идентичности. Любые совпадения с реальными гражданами, должностными лицами, номерами документов или событиями являются абсолютно случайными.

Проект разработан для среды **Embarcadero Delphi 10 / 11 / 12 / RAD Studio (Win32/Win64)**. Предназначен для высокоскоростной автономной фильтрации больших массивов табличных данных без необходимости установки внешних офисных пакетов.

---

## 🎯 Основные возможности

### 1. Анализ повторных записей
* Автоматическое сканирование табличной базы (18 000+ строк) за сотые доли секунды (< 50 мс) с использованием быстрого алгоритма хеш-индексации $O(1)$.
* Выявление записей с повторными решениями во времени с группировкой по связке идентификатора подразделения и номера документа.
* Сбор полной хронологии дат решений по каждому объекту.
* Экспорт готового реестра отчетов в текстовый файл одним нажатием.

### 2. Ручной точечный фильтр
* Поиск по конкретному номеру или списку номеров через запятую (например: `100101, 200202, 300303`).
* Дополнительная фильтрация по дате решения.
* Пастельная эргономичная цветовая индикация ключевых колонок для снижения утомляемости глаз.

### 3. Автономность и кросс-платформенность Windows
* **Работает без Microsoft Excel:** приложение оснащено собственным модулем разбора CSV/XLSX, совместимо с системами без установленного MS Office (ONLYOFFICE, LibreOffice или чистая ОС).
* **Совместимость с Windows:** благодаря директивам PE-заголовка (`5.1`) поддерживается запуск на Windows XP, Vista, 7, 8, 10 и 11 (32-бит и 64-бит).

---

## 🚀 Сборка и запуск проекта

1. Откройте файл проекта **`XlsFilterUnified.dproj`** в среде **Embarcadero Delphi / RAD Studio**.
2. Нажмите **`Shift + F9`** (Сборка / Build), затем **`F9`** (Запуск / Run).
3. Нажмите кнопку **«Обзор и загрузка файла...»** и выберите файл базы данных (`МЕГА_БАЗА_ИЦ_МВД_Уголовные_Дела.csv`).
4. Нажмите **«Выполнить анализ повторов»** для построения аналитического отчета.
